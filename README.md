# Monarch Baweja Portfolio

Premium dark cinematic portfolio for Monarch Baweja, focused on Data Analytics, Data Science, Business Analytics, and AI/ML roles.

## Local Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

This repo includes a GitHub Pages workflow at `.github/workflows/deploy.yml`. Push the `main` branch to GitHub, then enable Pages with **GitHub Actions** as the source in repository settings.
